## About Guess The Word
Unlike traditional five-letter spelling games, **Guess The Word** is a semantic word puzzle where guesses are ranked by conceptual closeness and semantic context to a secret mystery word.

## Features
- **Daily Challenge:** Solve the new secret word each day with semantic feedback.
- **Unlimited Practice:** Hundreds of practice rounds with no wait time.
- **Friend Challenge:** Generate custom secret word puzzles with unique challenge links.
- **Smart Hints:** Directional and lexical clues to help narrow down guesses.
